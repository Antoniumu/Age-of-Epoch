# Публикация на Modrinth

## Автоматические alpha-сборки

Workflow `.github/workflows/branch-release.yml` публикует alpha-сборку на Modrinth после успешной сборки push в ветку `arena/ad7c45b3-age-of-epoch`. После настройки секретов его можно также запустить вручную на этой ветке, например, чтобы опубликовать текущий коммит без нового push. Pull request ничего на Modrinth не загружает. Изменения только в `modrinth/project-metadata.json` или `modrinth/project-icon.png` не создают лишнюю alpha-версию.

В настройки каждой автоматически публикуемой версии добавляются обязательные зависимости Fabric API и Trinkets Updated.

## Однократная настройка репозитория

В настройках GitHub-репозитория откройте **Settings → Secrets and variables → Actions** и добавьте:

- **Repository secret** `MODRINTH_TOKEN` — токен Modrinth; храните его только в секретах Actions, не добавляйте в файлы репозитория или сообщения.
- **Repository variable** `MODRINTH_PROJECT_ID` — ID проекта Modrinth (значение из страницы проекта или его URL).

Для загрузки alpha-версий токен должен иметь разрешение на создание версий. Workflow заполнения страницы и отправки её на проверку также обновляет сведения о проекте и значок (разрешение `PROJECT_WRITE`) и добавляет обязательные зависимости к последней существующей версии (разрешение `VERSION_WRITE`). Убедитесь, что токену выданы все нужные разрешения.

Пока любая из настроек отсутствует, CI пропускает публикацию/изменение на Modrinth и продолжает сборку и выпуск JAR на GitHub.

## Поля страницы проекта и проверка

Файл `modrinth/project-metadata.json` — источник заголовка, краткого и полного описаний, категорий, ссылок, лицензии, клиентской/серверной совместимости и запроса на проверку. Значок страницы находится в `modrinth/project-icon.png`; используемая игровая иконка в `src/main/resources/assets/mmorpg/icon.png` совпадает с ним.

Workflow `.github/workflows/modrinth-review.yml` запускается при изменении этих файлов или вручную. Он проверяет конфигурацию, выставляет обязательные зависимости для последней версии Fabric/Minecraft 26.3, загружает значок, обновляет страницу и запрашивает статус `approved` для отправки на модерацию. Успешное выполнение должно подтвердить полученный статус проекта в сводке запуска. Запрос отправки не означает, что Modrinth уже одобрил проект: окончательное решение принимает модерация Modrinth.

## Что публикуется

- JAR из `build/libs` (sources/Javadoc JAR исключены);
- loader: Fabric;
- Minecraft: 26.3; Java: 25;
- канал: **alpha**;
- уникальная версия вида `5.0.0-arena.<номер запуска CI>`.

Каждое обновление исходников ветки создаёт отдельную версию Modrinth и prerelease GitHub с тем же JAR.
