# Сценарий: аудит ВСЕХ профессий ремесла — настоящая сетка крафта 3×2,
# раскладка ингредиентов МЫШЬКОЙ и запись видео.
#
# Что здесь важно:
#   * мир создаётся тем же путём, что в combat/spells — координаты проверены CI;
#   * аудит запускает флаг-файл run/aoe-profession-audit.flag: ProfessionAuditProbe
#     выдаёт инструмент + ингредиенты и следит за контейнером, а сценарий двигает
#     предметы настоящими кликами;
#   * КАЖДОЕ перемещение предмета в слоты сетки крафта (3×2) сопровождается
#     отдельным скриншотом — сетка видна в кадре целиком;
#   * запись видео (ffmpeg/x11grab) стартует ДО флага, чтобы в кадр попали и
#     проверки, и первый клик, и останавливается после AOEPR done;
#   * координаты — под окно 1280x720 (run/options.txt, guiScale 2):
#       ProfCraftScreen 176x207 центрируется: left=552, top=256;
#       слоты сетки 3×2 (центр): (673,275) (691,275) (709,275) / (673,293) (691,293) (709,293);
#       слот результата: (693,339);
#       хотбар: y=447, слоты 0..8 — x=568..712 шаг 18;
#       раздача зонда: 0 — инструмент (в руке), 1 — основа (гир-профессии),
#       2 — матрица душ (+20% успеха), 3/4 — обычные ингредиенты, 8 — пустой.
