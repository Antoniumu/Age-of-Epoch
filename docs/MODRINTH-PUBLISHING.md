# Публикация и лицензирование

## Пауза публикаций

Автоматические публикации исходников, JAR и alpha-версий на Modrinth и GitHub временно отключены, пока уточняются права на код и материалы исходного Age of Exile. Workflow `.github/workflows/branch-release.yml` оставлен только для проверки сборки: он не создаёт релизы и не загружает артефакты. Автоматический workflow обновления страницы Modrinth удалён.

Ранее загруженные alpha-версии Modrinth и GitHub prerelease не удаляются этим изменением. Они могут оставаться доступными, если проект/репозиторий публичны. Перед публикацией новых версий сначала нужно подтвердить разрешение правообладателей и проверить условия лицензии.

## Метаданные Modrinth

`modrinth/project-metadata.json` и `modrinth/project-icon.png` сохранены как подготовленные материалы страницы. Они не публикуются автоматически. Не включать публикацию обратно, пока не прояснено право распространять порт и его материалы.
