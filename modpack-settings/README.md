# Лёгко-средний профиль настроек Age of Epoch

Файл [`options.txt`](options.txt) создан из присланного пользователем файла. Настройки рассчитаны
на конфигурацию из crash report: **4 потока CPU, Radeon Pro 570 4 ГБ, тяжёлую сборку с DnT**,
без включённых шейдеров и без Distant Horizons.

## Как установить

1. Полностью закройте Minecraft.
2. Сделайте резервную копию текущего `options.txt`.
3. Скопируйте наш `options.txt` в папку `minecraft` выбранного instance — туда, где уже находятся
   `mods`, `config` и прежний `options.txt`. В ElyPrismLauncher папку можно открыть через настройки
   сборки/кнопку открытия папки Minecraft.
4. Запустите игру и проверьте новый тестовый мир. Не выставляйте обратно render distance 16 до
   проверки FPS в большом DnT-данже.

Не копируйте этот файл в исходники мода: он предназначен для папки запускаемого клиента.

## Что изменено для лёгко-среднего профиля

| Параметр | Было | Стало | Зачем |
|---|---:|---:|---|
| `renderDistance` | 16 | **8** | Главное снижение нагрузки на CPU/GPU и память в структурах. |
| `simulationDistance` | 12 | **8** | Умеренное снижение активной области в одиночной игре; не опускается до 4–6 ради сохранения нормального спавна. |
| `particles` | All | **Decreased** | Меньше нагрузка от частиц, но заклинания и атаки остаются читаемыми. |
| `biomeBlendRadius` | 7 | **2** | Меньше работы по сглаживанию цветов биомов Terralith/Tectonic. |
| `entityDistanceScaling` | 1.0 | **0.75** | Снижает дальность отрисовки сущностей, не отключая их полностью. |
| `entityShadows` | true | **false** | Убирает дополнительную отрисовку теней большого числа существ. |
| `maxFps` | 120 | **60** | Более спокойный режим для GPU; VSync оставлен включённым. |
| `weatherRadius` | 10 | **6** | Меньше погодных эффектов вокруг игрока. |
| `glDebugVerbosity` | 1 | **0** | Отключает лишний вывод отладки графического драйвера. |
| `menuBackgroundBlurriness` | 5 | **0** | Убирает размытие фона меню. |

Намеренно сохранены: **AO, cutout leaves, mipmap 4, отключённые облака, VSync, отсутствие fade-in
секций, язык, GUI scale, FOV, чувствительность мыши, громкость, субтитры и параметры доступности**.
`syncChunkWrites` не отключается: небольшая возможная экономия дискового времени не стоит риска
повреждения мира при аварии.

## Клавиши и конфликты

- **Iris:** перезагрузка шейдеров перенесена с R на **F7**, переключение шейдеров с K на **F8**.
  Теперь **R остаётся заклинанию Age of Epoch**, а **K — квестбуку**.
- Vanilla Quick Actions отвязано от **G**, чтобы не пересекаться с четвёртым заклинанием Age of Epoch.
- Три необязательные команды сжатия Crafting Tweaks отвязаны от **K**; сами функции остаются
  доступны через кнопки интерфейса.
- Удалены восемь старых клавиш Traveler's Backpack: этого мода нет в рекомендуемой сборке и в
  присланном crash report. Клавиша **B** остаётся терминалу Tom's Storage.
- Остальные клавиши, включая **H/J/K** и заклинания **R/V/C/G**, сохранены.

## Настройки модов, которые не хранятся в options.txt

`options.txt` не содержит TOML/JSON-конфиги Sodium Extra, Dynamic FPS, LambDynamicLights,
Sound Physics, Xaero, DnT и остальных модов. Неизвестные ключи в него не добавлялись.

Для текущего профиля действуют следующие правила:

- **Шейдеры:** выключены, как в присланном crash report.
- **Distant Horizons:** не устанавливать вместе с Chunky 1.5.3; основная сборка использует Chunky без DH.
- **LambDynamicLights:** в Mod Menu выбрать **Fast** вместо показанного в crash report **Fancy**,
  если нужна дополнительная экономия CPU. Его конфиг в присланный файл не входит.
- **Sodium / Iris:** сначала проверять стабильные Sodium 0.9.2 + Iris 1.11.7. Установленная
  Sodium 0.9.3-beta.1 не была причиной падения Chunky, но не является предпочтительной базой профиля.
- **Lithium, FerriteCore, ImmediatelyFast, EntityCulling, BadOptimizations, Krypton, Debugify,
  Structure Layout Optimizer:** оставить значения по умолчанию; отключение их функций обычно только
  ухудшает работу сборки.
- **Dynamic FPS:** значения по умолчанию и уже включённое AFK-ограничение сохраняются.
- **Farmer's Delight, Cooking for Blockheads, JEI, Jade, Macaw's и интерфейсные моды:**
  специального «лёгкого» пресета не требуется; важнее не дублировать HUD и recipe viewer.
- **Age of Epoch, DnT, Naturalist, Friends&Foes, Variants&Ventures, More Mobs и worldgen:**
  RPG-баланс, лут, спавн и плотность структур этим файлом не изменяются. Их нельзя «оптимизировать»
  графическими настройками.

Для точной записи настроек **всех** модов нужны автоматически созданные игрой файлы из папки
`config` (и при необходимости `defaultconfigs`). Без них создание десятков конфигов с нуля было бы
догадкой: названия и допустимые значения ключей различаются даже между версиями одного мода.

## После запуска

1. Проверить **H/J/K**, заклинания **R/V/C/G**, **F7/F8** для Iris и **B** для Tom's Storage.
2. Сравнить FPS на базе и внутри большого DnT-данжа, а не только в пустом мире.
3. Если FPS всё ещё низкий: сначала render distance **8 → 6**, затем частицы **Decreased → Minimal**.
   Не уменьшайте simulation distance одновременно — так проще понять, что именно помогло.
4. Если производительности достаточно и хочется улучшить картинку: сначала частицы вернуть на All,
   затем render distance поднять до 10. Не начинайте с шейдеров или Distant Horizons.

Для выделенного сервера `simulationDistance` из клиентского `options.txt` не применяется:
`simulation-distance` и `view-distance` настраиваются отдельно в `server.properties` после проверки
нагрузки и требований баланса Age of Epoch.
