Рюкзак — отдельный инвентарь с автоматикой. Он не заменяет обычный инвентарь,
а разгружает его: собирает добычу и разбирает мусор без участия игрока.

## Базовый рюкзак

Обычный рюкзак (`mmorpg:backpack/normal`) открывается как контейнер и даёт
дополнительные слоты. В него же устанавливаются улучшения.

## Улучшения

| Улучшение | Что делает |
|---|---|
| Размер (5 уровней) | Увеличивает вместимость |
| Автосбор мусора | Подбирает обычный мусор |
| Автосбор эссенций | Подбирает пыль и эссенции |
| Автосбор самоцветов | Подбирает камни |
| Автосбор рун | Подбирает руны |
| Автосбор валюты | Подбирает валюту |
| Авторазбор обычных | Разбирает белые предметы |
| Авторазбор необычных | Разбирает зелёные предметы |
| Авторазбор редких | Разбирает синие предметы |
| Сохранение важного | Не разбирает именованные и зачарованные предметы |

Улучшения ставятся в рюкзак и работают пассивно. Каждое улучшение имеет свой уровень
(тир), который определяет, какие предметы оно затрагивает.

## Зачем это нужно

После данжа остаётся 30–50 предметов. Вручную их разбирать — это минуты,
которые не хочется тратить. Авторазбор превращает этот процесс в фон.

## Осторожно

- Авторазбор может съесть предмет, который ты хотел оставить: включай
  «сохранение важного».
- Улучшения не переносятся между рюкзаками.
- Автосбор не работает на расстоянии: предметы должны быть рядом.
