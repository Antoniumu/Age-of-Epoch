# Age of Epoch 5.2.6-beta.1 — test build

**Beta, not a stable release. Back up your world and use a test world first.**

## Included

- Latest launcher metadata and icon from PR #133.
- Ascended classes from PR #134, unlocked at level 50. The first path is the
  **Tide Dancer**, with six abilities, three ranks per ability, a progression
  screen, custom icons and three-dimensional water effects.
- Registration fix for the Tide Dancer's beneficial and harmful status effects.
- Spell audit coverage for ascension abilities and their custom particle action.

## Installation

- Minecraft **26.3**, **Fabric Loader 0.19.5+**, **Java 25+**.
- Required mods: **Fabric API 0.163.0+** for Minecraft 26.3 and
  **Trinkets Updated 4.2.1+** for Minecraft 26.3.
- Install `Age-of-Epoch-5.2.6-beta.1.jar` on both the client and server.
- JEI is optional. The `-sources.jar` is for development, not installation.

This is a test release of the new progression system, not a claim of a complete
manual playthrough or production-server readiness. File hashes are in
`SHA256SUMS.txt`.
