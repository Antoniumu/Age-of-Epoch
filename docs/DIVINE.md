# Класс «Божественный» — древо призыва

Отдельная страница в древе талантов, из которой собирается **некромант** (игра от призыва убитых
врагов) или **призыватель** (постоянные звери: стая волков, медведь или боевой мамонт).

Это второе древо типа `TALENTS`: в игре оно открывается там же, где и основное древо талантов
(клавиша **H** → вкладка «Таланты»), переключение между древами — вкладками с иконками сверху и
стрелками по краям экрана. Очки талантов общие для всех древ одного типа (`TALENTS`), сброс узла —
ПКМ по нему (тратит очко сброса).

- Древо: `src/main/resources/data/mmorpg/talent_tree/divine.json`
- Перки: `DivinePerks.java`
- Статы: `SummonStat.java` (пассивные) и `DivineStats.java` (срабатывают на убийстве)
- Механика: `com.robertx22.age_of_exile.summoning` (`MinionUtils`, `MinionTick`)

## Как устроена страница

Как и договаривались: **по бокам — выбор типа призыва, в центре — общие перки**.

```
     НЕКРОМАНТ                    ОБЩЕЕ                   ПРИЗЫВАТЕЛЬ
  ┌───────────────┐          ┌──────────────┐          ┌───────────────┐
  │ Гнилая плоть  │          │ Власть над   │          │  Стая волков  │
  │ Холодная      │          │  слугами     │          │  Медведь-     │
  │  ярость       │          │              │          │   хранитель   │
  │      Восстание│──┐    ┌──│ Воля хозяина │──┐    ┌──│ Боевой мамонт │
  │ Властелин     │  │    │  │              │  │    │  │               │
  │  мертвецов    │  ├─Путь│  ──центр──     │Путь─┤  ├─ Звериный      │
  │ Взрыв трупа   │  │некро-│ Узы власти    │призы-│  │  оскал         │
  │ Цепная смерть │──┘манта │ Духовная связь│вателя│──│ Вожак стаи     │
  │ Легион        │          │ Долгий срок  │          │ Быстрые лапы  │
  └───────────────┘          │ Костяной     │          │ Густая шерсть │
                             │  панцирь     │          └───────────────┘
                             │ Плоть и кость│
                             └──────────────┘
```

Всего 24 узла: **8 некромант / 8 общих / 8 призыватель**.

Стартовых узла два — «Путь некроманта» слева и «Путь призывателя» справа (`is_entry`), с них
начинается любое развитие страницы; дальше узлы открываются по связям, как в обычном древе.

## Взаимоисключение веток

Некромант и призыватель **не могут быть взяты одновременно** — иначе два типа призыва сразу
давали бы слишком много. Сделано это не «разрезанием» страницы, а отдельным полем перка:

- `Perk.exclusive_branch` — формат «класс/путь»: `"divine/necromancer"` у левых узлов,
  `"divine/summoner"` у правых, `"divine"` у общих узлов центра;
- `Perk.branchesConflict(mine, taken)`: разные классы конфликтуют всегда, внутри класса конфликтуют
  только разные пути. `Perk.isLockedToPlayer()` проверяет все изученные узлы персонажа, поэтому
  общие узлы «Божественного» и ветки блокируют «Скверноводца» целиком (см. `BLIGHTCALLER.md`);
- в подсказке узла пишется «Взаимоисключающая ветка: Некромант/Призыватель», а при попытке взять
  закрытый узел — «Выбрана другая ветка призыва. Сначала сбросьте её таланты.»;
- общие перки доступны обоим билдам — они стоят в центре и не выбирают путь, но входят в класс.

Поле синхронизируется клиенту вместе с перком (`Perk.toBuf`/`getFromBuf`), поэтому подсказки
и блокировки одинаковы на обеих сторонах.

Внутри ветки призывателя тоже есть выбор одного из трёх: у «Стаи волков», «Медведя-хранителя»
и «Боевого мамонта» стоит `one_of_a_kind = "divine_beast"` — держать можно только один вид зверей.

Пассивные (`SummonStat`, читаются при призыве):

| Id | Название | Тип |
|---|---|---|
| `summon_damage` | Урон прислужников | % |
| `summon_health` | Здоровье прислужников | % |
| `summon_duration` | Время жизни прислужников | % |
| `summon_speed` | Скорость прислужников | % |

| Id | Название | Эффект |
|---|---|---|
| `raise_dead_chance` | Шанс поднять мёртвых | `RaiseDeadAction` — поднимает врага нежитью |
| `corpse_explosion` | Взрыв трупа | `ExplodeCorpseAction` — урон по площади от здоровья трупа |

## Как это работает в игре

Общее для обоих билдов:

- прислужник помечается тегами сущности (`mmorpg_minion`, владелец, вид, время исчезновения) —
  они пишутся в NBT, так что перезаход на сервер прислужников не теряет;
- сила берётся из статов хозяина и навешивается модификаторами атрибутов при призыве
  (здоровье, урон, скорость, броня, сопротивление отбрасыванию, дальность следования);
- базовое время жизни — 30 секунд, увеличивается от «Времени жизни прислужников», потолок — 5 минут;
- прислужник телепортируется к хозяину дальше 28 блоков, догоняет его дальше 10 блоков;
- цель ищется в радиусе 20 блоков, атакуются только враждебные существа: **игроков и чужих
  прислужников свои прислужники не бьют**;
- если хозяин умер, вышел с сервера или ушёл в другое измерение — прислужники рассеиваются.

Некромант:

- при каждом вашем убийстве враждебного существа кидается шанс «Шанс поднять мёртвых»;
- поднимается случайная нежить, состав зависит от уровня: до 10 — зомби и скелет, с 10 к ним
  добавляются кадавр и зимогор, с 25 — утопленник, с 40 — скелет-иссушитель;
- количество одновременных мертвецов ограничено «Пределом нежити» (лимит не превышается —
  лишний труп просто не поднимается);
- «Взрыв трупа» наносит процент от здоровья убитого врага физическим уроном в радиусе 4 блоков;
  урон идёт от игрока, поэтому на него действуют криты, пробивание и прочие ваши статы.

Призыватель:

- раз в 2 секунды проверяется, сколько зверей рядом; если меньше «Предела зверей» — призывается
  ещё один рядом с хозяином;
- вид зверя берётся из маркера: волк (`WOLF`), белый медведь (`POLAR_BEAR`) или боевой мамонт
  (`RAVAGER` — в ванили мамонта нет, взят самый крупный боевой зверь; если появится мод с
  мамонтом, достаточно поменять одну строку в `MinionUtils.beastType`).

## Баланс и что крутить

- сила прислужников — только проценты от ванильных мобов вашего уровня (`applyPerkStats`),
  то есть они масштабируются вместе с миром, а не «в вакууме»;
- «Боевой мамонт» при пределе 2 и +50% здоровья — самый сильный вариант ветки, он же самый
  поздний (уровень 25). Если окажется имбой — уменьшайте `+50%` здоровья или предел;
- у скелета-лучника атрибутом `ATTACK_DAMAGE` масштабируется только ближний бой, урон стрел
  ванильный — это ограничение ванили, а не бага статов;
- время жизни, радиусы и интервалы — константы в `MinionUtils` (`BASE_LIFETIME_TICKS`,
  `MAX_LIFETIME_TICKS`, `SEARCH_RADIUS`, `FOLLOW_DISTANCE`, `TELEPORT_DISTANCE`,
  `BEAST_CHECK_TICKS`).
