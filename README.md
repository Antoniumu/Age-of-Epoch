# Age of Epoch — порт Age of Exile на Minecraft 26.3 (Fabric)

Полный порт мода **[Age of Exile](https://github.com/RobertSkalko/Age-of-Exile)** (MMORPG-хак-н-слэш для Minecraft 1.16.5, Forge)
на **Minecraft 26.3 «Wilderness Bound» + Fabric**, с **полной русской локализацией**.

В состав порта включены (как единый мод):
- **Age of Exile** — ядро мода (заклинания, характеристики, аффиксы, снаряжение, данжи, карты приключений, профессии…);
- **Library of Exile** — общая библиотека (реестры JSON-базы данных, пакеты, капабилити, события);
- **Divine Missions** и **Infinite Dungeons** — аддоны, интегрированные в исходниках Age of Exile.
- **Тематические башни** — 16 тем по биомам, 3 уровня сложности и 80 боссов; см. [`TOWERS.md`](TOWERS.md).
- **GameMaster** — динамическая подстройка опыта: догоняющий режим для отстающих,
  растягивание развития до заданных реальных часов и **автобаланс** — «режиссёр», который
  держит игрока в коридоре ~14→70 минут на уровень и сам двигает опыт, HP/урон мобов и лут
  (см. [`GAMEMASTER.md`](GAMEMASTER.md)); локальная веб-панель с графиками.

## Сборка

Требования: **JDK 25**, доступ в интернет к `maven.fabricmc.net` и Mojang-репозиториям.

```bash
./gradlew build          # результат: build/libs/Age-of-Epoch-*.jar
./gradlew runClient      # запуск клиента для проверки
```

На Windows удобнее `build.bat` (сам находит JDK 25, кэши держит в `.gradle-home`):

```bat
build.bat                :: собрать мод
build.bat repair         :: починить сборку: сброс кэшей Loom/Minecraft + --refresh-dependencies
build.bat diagnose       :: build-diagnose.txt: видит ли javac Minecraft на classpath
```

Если `compileJava` сыплет `package net.minecraft.* does not exist` и падает с
`NullPointerException` в `TypeElement.getNestingKind()` — это не код, а Loom-артефакт Minecraft:

```bat
build.bat diagnose                :: build-diagnose.txt: на каком шаге jar стал пустым
build.bat probe                   :: повторяет шаг слияния Loom и печатает скрытое исключение
build.bat jcheck                  :: сравнить JDK: не врёт ли Files.isWritable()
build.bat repair                  :: сброс кэшей + --refresh-dependencies
build.bat singlejar client        :: собрать без слияния client+server (если zipfs в порядке)
```

`minecraft-merged-<hash>-26.3.jar (22 bytes)` — пустой zip: скачанные client/server целы,
а слияние Loom пишет пустоту и молча теряет исключение (`MinecraftJarMerger` не сохраняет
`Future` своих задач). На JDK 25 zipfs объявляет jar read-only, как только
`Files.isWritable()` вернёт `false`, и первая же запись падает с `ReadOnlyFileSystemException`.
Если `build.bat probe` показывает `Files.isWritable = false` там, где запись реально проходит —
врёт сам JDK: `build.bat jcheck` сравнит все установленные JDK, рабочий нужно поставить
в `.jdks\` или указать в `JAVA_HOME`. Подробности — [`BUILD-REPORT.md`](BUILD-REPORT.md) §6.

## Управление

Всё управление прежнее (кнопка H — хаб, панель заклинаний и т.д.), перевод выполнен
с сохранением цветовых кодов (§) и плейсхолдеров (`%1$s`, `[VAL1]`, `[calc:...]`).

Дополнительно: **J** — переключение стиля плашек мобов (см. ниже), **K** — открыть квестбук.

## Квестбук

Книга Эпохи доступна клавишей **K**, из вкладки в H-хабе или командой `/slash open questbook`.
Она ведёт от стартового набора через характеристики, экипировку, профессии, самоцветы, руны,
миссии, подземелья и башни до максимального уровня. Отдельную добровольную ветку на 100%
можно включить в книге: звание **Платина** требует закрыть основной маршрут и весь коллекционный
контент. Подробное прохождение, эффекты всех самоцветов и полный ростер башенных боссов —
в [`docs/QUESTBOOK.md`](docs/QUESTBOOK.md).

## Класс «Божественный» — древо призыва

Вторая страница древа талантов (**H** → «Таланты», переключение стрелками по краям экрана). Из неё
собирается **некромант** — игра от призыва убитых врагов — или **призыватель** — постоянные звери:
стая волков, медведь или боевой мамонт.

Страница разделена на три части: **слева — некромант, справа — призыватель, в центре — общие перки**
(8 узлов в каждой части). Ветки взаимоисключающие: пока взят хотя бы один перк некроманта, узлы
призывателя закрыты, и наоборот; внутри ветки призывателя держать можно только один вид зверей.

Поднятые мертвецы живут от 30 секунд до 5 минут, их здоровье, урон, скорость и броня растут от
характеристик хозяина, и они не трогают игроков; убитые враги могут взрываться; звери призываются
сами, пока их меньше предела. Таблицы перков, список характеристик и ручки баланса —
в [`docs/DIVINE.md`](docs/DIVINE.md).

## Плашки мобов

Над мобами рисуется табличка с именем, уровнем, редкостью и здоровьем. Есть три стиля:

| Стиль | Как выглядит |
|---|---|
| `CLASSIC` | Две строки текста и полоса здоровья из символов `|` — как в оригинальном Age of Exile. |
| `MODERN` (по умолчанию) | Тёмная «стеклянная» плашка со скруглёнными углами, рамкой в цвет редкости, бейджем уровня и плавной полосой здоровья (красный → янтарный → зелёный). |
| `RUNE` | Плашка с золотой огранкой, самоцветом-бейджем уровня, сегментированной полосой здоровья и указателем-каплей к мобу. |

Плашки сами скрываются на расстоянии, за спиной камеры и над невидимыми/мёртвыми мобами;
уровень мобов, которые намного сильнее игрока, показывается как `??`.

### Настройка

Файл `config/age_of_epoch/mob_plates.properties` создаётся при первом запуске:

```properties
style=MODERN              # CLASSIC | MODERN | RUNE
scale=1.0                 # 0.6 … 1.8 — общий размер плашки
max_distance=24           # 8 … 64 — дальность отрисовки в блоках
show_level=true           # бейдж уровня
show_hp_text=true         # числа «текущее/максимум» рядом с полосой
only_looked_at=false      # рисовать только у моба под прицелом
hide_full_health=false    # скрывать плашки мобов с полным здоровьем
show_players=true         # рисовать плашки и над игроками
```

Нажатие **J** в игре циклически переключает стиль и сразу сохраняет выбор в этот файл,
поэтому стиль не сбрасывается после перезапуска.

## Подземные экспедиции

Добавлена первая реализация конечных четырёхэтажных данжей: **4 темы, 12 планировок,
64 комнаты на комплекс**, возрастающая сложность, стражи спусков, финальная награда

#### Выбор рабочего JDK 25

`build.bat` пропускает JDK, не прошедшие проверку записи в проект и Gradle-кэш.
`build.bat jcheck` выдаёт сводку без дублей: JDK 21 можно сравнить, но собирать нужно 25+.
Ошибки отдельных путей больше не скрываются успешной проверкой другого пути.

```bat
build.bat getjdk microsoft
build.bat jcheck
build.bat repair
```

Для установки Microsoft требуется winget с пакетом `Microsoft.OpenJDK.25`.
`getjdk` без аргумента по-прежнему скачивает Temurin; переменная `AOE_JDK_URL`
позволяет указать доверенный HTTPS ZIP другого JDK. После установки выполняется проверка.
Подробности и ограничения диагностики — в дополнении к §6 `BUILD-REPORT.md`.
