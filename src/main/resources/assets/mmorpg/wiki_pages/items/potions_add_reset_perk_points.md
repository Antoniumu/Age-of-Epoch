# Зелье сброса одного таланта

Раздел: [[categories/potions|Особые зелья]]. Подробности системы: [[guides/food-potions|Еда и зелья]].

## Описание

ПКМ — выпить: +5 очков сброса талантов.

Очко сброса убирает один талант без потери остальных.

Остаётся пустая бутылка.

## Получение

Рецепты из датапака мода:

- **крафт на верстаке по форме (ингредиенты раскладываются рисунком)**:
  - алмаз (`minecraft:diamond`) ×3
  - стеклянная бутылка (`minecraft:glass_bottle`)
  - [[items/mat_salvage_salvage0|Очищенная эссенция 0-го ранга]]
