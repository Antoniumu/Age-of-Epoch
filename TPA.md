# TPA — телепортация по запросу

Аддон доступен всем игрокам без прав оператора.

## Команды

| Команда | Действие |
|---|---|
| `/tpa <игрок>` | Отправить игроку запрос на телепортацию к нему |
| `/tpaccept [игрок]` | Принять последний запрос или запрос указанного игрока |
| `/tpdeny [игрок]` | Отклонить последний запрос или запрос указанного игрока |
| `/tpacancel` | Отменить свой исходящий запрос |
| `/tpa <x> <y> <z>` | Телепортироваться на координаты в текущем измерении |
| `/tpa trust <игрок>` | Автоматически принимать запросы этого игрока |
| `/tpa untrust <игрок>` | Отключить автопринятие запросов этого игрока |
| `/tpa trusted` | Показать список доверенных игроков |
| `/tpa charges` | Показать заряды и время до следующего восстановления |
| `/tpa` или `/tpa help` | Показать краткую справку |

У `/tpa accept`, `/tpa deny` и `/tpa cancel` есть те же функции, что у отдельных команд `/tpaccept`, `/tpdeny` и `/tpacancel`.

## Заряды

- Максимум — **10 зарядов** у каждого игрока.
- Восстанавливается **1 заряд каждые 10 минут**, пока не наберётся 10.
- Восстановление идёт по реальному времени, включая выход игрока и перезапуск сервера.
- Заряд тратит только телепортирующийся игрок и только **после успешной телепортации**.
- Отправка, отмена, отклонение и истечение запроса зарядов не тратят.

## Запросы и доверие

Запрос действует **60 секунд**. Без аргумента `/tpaccept` и `/tpdeny` выбирают самый новый входящий запрос. Новый исходящий запрос к другому игроку заменяет предыдущий.

Доверие настраивает получатель. Например, после команды `/tpa trust Steve` у Alex запросы Steve к Alex будут приниматься автоматически. Это не включает автопринятие запросов Alex для Steve: при необходимости Steve должен отдельно выполнить `/tpa trust Alex`.

Координатная форма поддерживает относительные координаты, например `/tpa ~ ~10 ~` или `/tpa 100 64 -250`.
